# Python RAG Teaching Assistant — Flask migration starter

This is an isolated Flask starter. It does **not** overwrite your existing Streamlit `app.py`.

## 1. Files to keep in this folder
- `flask_app.py`
- `requirements.txt`
- `templates/`
- `static/`
- `.env` (create locally; do not commit it)
- Later, we will add `embeddings.joblib` and `urls.txt` here or configure their paths.

## 2. Set up on Windows
Open CMD/PowerShell in this folder:

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Open `.env` and set the values from your existing local `.env`:
- `SESSION_SECRET`
- `SUPABASE_URL`
- `SUPABASE_KEY`

Do not paste your keys into chat or upload `.env`.

## 3. Run locally
```powershell
python flask_app.py
```
Open `http://127.0.0.1:5000`.

Health check: `http://127.0.0.1:5000/health`

## 4. Supabase requirement
This starter uses the same custom `users` table and fields as the current Streamlit app:
- `id`
- `name`
- `email`
- `password_hash`

It assumes `id` is generated by the database and `email` is unique. The Supabase key must have permission to select/insert rows in `users`. If your existing Row Level Security policies block these operations, do not disable RLS blindly; we will configure a safe server-side approach in the next step.

## 5. Render deployment settings
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn flask_app:app`
- Add `SESSION_SECRET`, `SUPABASE_URL`, `SUPABASE_KEY` as environment variables.
- Set `COOKIE_SECURE=true` in production.
- Never upload `.env` to GitHub.

The free plan can sleep after inactivity. Free-tier limits can change.

## Current milestone
Included: Flask app, responsive login/signup pages, password hashing, persistent signed session, logout, CSRF form token, health endpoint, and a dashboard placeholder.

Not yet included: RAG retrieval, Jina embedding calls, Groq answer generation, chat history, learning memory, activity logs, video recommendations, or course progress. Those are next milestones.
